# Verso V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer la V2 de Verso (confort de lecture) jusqu'à ce que tous les « Critères d'acceptation V2 » de `docs/SPEC.md` soient cochés.

**Architecture:** On garde les deux modules. `:core` (Kotlin JVM pur) reçoit les modèles et calculs nouveaux : réglages de lecture, état d'un livre avec choix manuel, statistiques, numéro de page. `:app` fait passer les réglages de DataStore au thème Compose (police et palette dynamiques) et au navigateur classique de Readium (`submitPreferences`), ajoute le mode pages (pagination native de Readium), la feuille « Aa », les filtres de bibliothèque, les statistiques et la recherche (service de recherche de Readium). La machine à états de la position de lecture ne change pas.

**Tech Stack:** celle de la V1 (Kotlin 2.4.20 intégré à AGP 9.4.1, Compose BOM 2026.09.00, Material 3, Navigation 2.10.2, Room 2.8.5, DataStore 1.2.1, Coil 3.6.3, Readium kotlin-toolkit 3.4.0, JUnit 4, Truth, Turbine, Robolectric 4.17, Roborazzi). Aucune dépendance nouvelle.

**Spec:** `docs/SPEC.md` (V2 — Confort de lecture, Réglages de la V2, Critères d'acceptation V2) et `docs/superpowers/specs/2026-09-27-verso-v2-design.md`. Maquettes : `docs/design/screens/2.0*.png` et `docs/design/html/2.0*.html` (libellés exacts, mesures). Référence Readium : `docs/superpowers/plans/research-readium-3.4.md`.

## Décisions prises en rédigeant le plan

- **Seuils du mode pages** : avec les seuils du continu, la confirmation « 25 s de lecture » ne se déclenche jamais en pages (une page se lit en 60 s environ, plus que la pause maximale de 15 s, et chaque tour avance de plus d'un écran). La machine à états garde ses règles ; seuls des seuils propres au mode pages sont posés (`ReadingThresholds.forPages()` : pause maximale 90 s, dérive 2,5 écrans), reportés dans la spec à l'étape 12.
- **Libellés absents des maquettes**, proposés dans l'esprit des maquettes et à confirmer par Maxime à la fin de l'étape concernée : « Aucun livre pour ce filtre. » (13), « N résultats dans le livre » et « Aucun résultat dans le livre » en fin de recherche (15).

- **Aucune permission**, pas de `INTERNET`, pas d'analytics ; `scripts/check-no-internet.sh` reste vert. Rien ne quitte le téléphone.
- Aucun texte en dur : tout libellé dans `app/src/main/res/values/strings.xml`, repris **mot pour mot** des maquettes HTML V2 (`docs/design/html/2.0*.html`). Espace fine insécable U+202F avant `; : ! ?`, `%` et à l'intérieur de « … » ; U+00A0 dans les durées (« 2 h 28 ») ; apostrophe typographique ’ ; « Environ » jamais « ≈ ». `StringsTest` vérifie ces règles.
- Aucune couleur en dur : couleurs de `VersoPalette` (générée depuis `docs/design/tokens.json`). Palettes : `Light`, `Sepia`, `Dark`, `Black` (déjà générées).
- Accessibilité : contraste du texte ≥ 7:1, non-texte ≥ 3:1 ; commandes ≥ 48 dp ; tailles et interlignes en sp ; texte à 200 % sans coupure ni scroll horizontal ; intitulé TalkBack sur chaque bouton à icône seule ; jamais la couleur seule pour porter une information (coche, gras, soulignement, texte) ; « Supprimer les animations » respecté (`ui/a11y/ReducedMotion.kt`).
- Lecture : alignement à gauche, sans justification ni césure, `publisherStyles = false`, par-dessus le CSS de l'éditeur, dans tous les modes et tous les réglages.
- Position de lecture : toujours un locator Readium, jamais des pixels. Seuils en constantes nommées. Changer un réglage (police, taille, interligne, marges, thème, défilement) garde le même locator.
- Réglages V2 (spec) : taille 20 sp par défaut, 14 à 32 par pas de 1, multipliée par l'échelle de police d'Android ; interligne 1,4 / 1,6 / 1,8 ; marges 16 / 24 / 32 dp ; Literata par défaut ; défilement mémorisé par livre, défaut global dans les Paramètres.

## Review Focus

1. **Base de la V1 sur le téléphone** : la migration Room 1 → 2 garde livres, positions et sessions ; un réglage DataStore V1 (`theme_mode` = `LIGHT`/`DARK`/`AUTO`) est relu tel quel ; une valeur inconnue revient au défaut. → `VersoDatabaseMigrationTest` et `SettingsRepositoryTest` (tâche 9.1, qui crée la seule migration de la V2).
2. **Réglage changé en pleine lecture** (taille +/− répétés vite, changement de police, bascule continu ↔ pages) : le même paragraphe reste à l'écran, la machine à états ne voit ni fling ni navigation, la progression ne bouge pas. → tests `ReaderViewModelTest` avec `FakeReaderController` (tâches 11.x et 12.x).
3. **Mode pages aux bords** : dernière page d'un chapitre → première du suivant, première page du livre (tour arrière sans effet), chapitre d'une seule page (« Page 1 sur 1 »), tap au centre (barre) contre tap latéral (page). → tests de `pageInChapter` (`:core`) et du contrôleur (tâche 12.x).
4. **Recherche** : requête vide ou d'un seul caractère (aucune recherche lancée), mot absent (« Aucun résultat »), mot très fréquent (liste qui s'allonge sans bloquer l'interface, annulation à la fermeture ou à une nouvelle saisie), accents et casse (« riviere » trouve « rivière » si Readium le permet ; sinon documenté). → tests `SearchViewModel` / `BookSearch` (tâche 15.x).
5. **Statistiques aux bornes** : aucune session (vitesse par défaut, pas de division par zéro), sessions très courtes (vitesse non affichée sous le seuil de temps actif), livre terminé (temps restant nul, pas négatif), interrupteur désactivé. → `ReadingStatsTest` (tâche 14.1).

```kotlin
package com.maximebier.verso.core.settings

enum class ReadingFont { LITERATA, ATKINSON, SYSTEM }
enum class LineSpacing(val factor: Double) { TIGHT(1.4), NORMAL(1.6), AIRY(1.8) }
enum class Margins(val dp: Double) { NARROW(16.0), NORMAL(24.0), WIDE(32.0) }
enum class ScrollMode { CONTINUOUS, PAGES }

object ReadingSettingsLimits {
    const val MIN_FONT_SIZE_SP = 14
    const val MAX_FONT_SIZE_SP = 32
    const val DEFAULT_FONT_SIZE_SP = 20
    const val FONT_SIZE_STEP_SP = 1
}

data class ReadingSettings(
    val font: ReadingFont = ReadingFont.LITERATA,
    val fontSizeSp: Int = ReadingSettingsLimits.DEFAULT_FONT_SIZE_SP,   // toujours dans MIN..MAX
    val lineSpacing: LineSpacing = LineSpacing.NORMAL,
    val margins: Margins = Margins.NORMAL,
    val defaultScrollMode: ScrollMode = ScrollMode.CONTINUOUS,
) {
    val canGrow: Boolean
    val canShrink: Boolean
    fun larger(): ReadingSettings      // +1 sp, borné
    fun smaller(): ReadingSettings     // −1 sp, borné
    fun withFontSize(sp: Int): ReadingSettings   // borné à MIN..MAX
}
```
